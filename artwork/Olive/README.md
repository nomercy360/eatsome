# Olive

The generated glossy olive, kept as the master.

Not shipped. `OliveRow` draws its olive in SwiftUI (`OliveMark`) rather than
using this: the mark renders at 9–36 pt, which is exactly the size where
photographic shading turns to mud, and the ghost state — the same drawing at
17% opacity — stopped reading as an olive at all once it was a raster.

Kept because it is the reference the drawn shape was matched to, and because
regenerating it would not produce the same olive twice.
